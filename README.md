# Vivadent — site (Vite + React)

```bash
npm install
npm run dev      # développement : http://localhost:5173
npm run build    # production : dossier dist/
```

- Tout le site est dans `src/App.jsx` (pages, textes, cliniques, carrousel).
- Les photos sont dans `public/uploads/`.
- Coordonnées et horaires des cliniques : constante `CLINICS` en haut de `src/App.jsx`.
